# Gear Cam — تشغيل الكاميرا الخلفية/الأمامية حسب القير

مشروع Android Studio جاهز (Java، بلا مكتبات خارجية، targetSdk 27 = أندرويد 8.1).

## السلوك
- القير **R** ← يفتح تطبيق الكاميرا الخلفية فوراً.
- القير **D** ← يفتح تطبيق الكاميرا الأمامية (AVIN) وتبقى **10 ثوانٍ** (قابلة للتعديل) ثم يعود للشاشة الرئيسية.
  إذا عاد القير إلى R خلال المدة تُلغى المؤقّت وتُفتح الخلفية.
- بعد R إذا أصبح القير N أو P لأكثر من 3 ثوانٍ ← العودة للرئيسية (3 ثوانٍ حتى لا يحدث وميض أثناء المرور بـ N من R إلى D).
- الخدمة تعمل في الخلفية وتبدأ تلقائياً مع إقلاع الشاشة.

## البناء
1. افتح مجلد `GearCam` في Android Studio (Hedgehog أو أحدث) ووافق على تحديث/إنشاء Gradle wrapper إن طلب.
2. Build ← Build APK(s). الملف: `app/build/outputs/apk/debug/app-debug.apk`.
3. انقله بفلاشة USB إلى الشاشة وثبّته (فعّل "المصادر غير المعروفة").

## الإعداد على الشاشة
1. افتح **Gear Cam**، اختر تطبيق الكاميرا الخلفية والأمامية (يُختار AVIN تلقائياً إن وُجد اسمه).
2. حدّد **مصدر إشارة القير** (انظر أدناه) واضغط "حفظ وتشغيل الخدمة".
3. جرّب "محاكاة R" و"محاكاة D" للتأكد من أن فتح التطبيقات يعمل قبل ربط القير الفعلي.

## كيف نعرف إشارة القير؟
كل شاشة صينية تُعلن القير بطريقة مختلفة، لذلك لا توجد طريقة موحّدة. استخدم **أداة اكتشاف إشارة القير** داخل التطبيق:
- **ابدأ الاستماع** ثم حرّك القير؛ إن غيّرت الشاشة قيمة في إعدادات النظام ستظهر في السجل.
- أو **لقطة A** (على P) ثم **لقطة B** (على R) ثم **قارن**؛ ستظهر القيم التي تغيّرت (إعدادات النظام وملفات sysfs).

مثال لما قد تجده وكيف تعبئه:
| ما وجدته | المصدر | الحقول |
|---|---|---|
| Broadcast اسمه `xxx.REVERSE` مع extra `gear` قيمته `R`/`D` | Broadcast | actions=`xxx.REVERSE`، key=`gear`، R=`R`، D=`D` |
| Broadcast مختلف لكل حالة (`xxx.REV_ON`، `xxx.REV_OFF`) | Broadcast | actions=`xxx.REV_ON,xxx.REV_OFF`، key فارغ، R=`xxx.REV_ON`، فعّل خيار "الرجوع فقط" |
| ملف مثل `/sys/.../reverse` قيمته `1` عند R و`0` غير ذلك | ملف نظام | المسار، R=`1`، فعّل "الرجوع فقط" |
| إعداد `gear_state` قيمته `R`/`D` | Settings | الاسم، R=`R`، D=`D` |

إن لم تظهر الأداة شيئاً (الإشارة تذهب لخدمة النظام عبر واجهة خاصة)، الطريقة الأدق عبر الكمبيوتر:
`adb connect <ip>` ثم `adb logcat -v time` وحرّك القير وابحث عن كلمات مثل `reverse` أو `gear` أو `acc`، وأرسل لي المقطع وأضبط لك الإعداد.

## ملاحظات
- كثير من الشاشات توقف التطبيقات الخلفية؛ أضف Gear Cam إلى قائمة **التشغيل التلقائي** وأوقف **توفير الطاقة** له.
- إن كانت الكاميرا الخلفية تعمل أصلاً من النظام عند R وتريد فقط تغطية D، اترك تطبيق الخلفية "غير محدد".
- السجل في الشاشة وفي logcat بوسم `GearCam`.
